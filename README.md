# Welcome to Reactjs Quest04
***

## Task
The goal of this challenge is to practice working with stateful and stateless components in ReactJS.

Stateful components (also known as smart/container components) manage and maintain their own state.

Stateless components (also known as dumb/presentational components) receive props and render UI accordingly.

## Description
This project consists of two parts:

Stateful Component (MyLocation.js)

A React class component that maintains a state variable location and displays its value.

Stateless Component (List.js)

A functional component that receives a list via props and renders it dynamically.

## Installation
To install and run the project, follow these steps:

bash
Copy
Edit
# Clone the repository
$> git clone https://github.com/your-repo/reactjs-quest04.git

# Navigate to the project directory
$> cd reactjs-quest04

# Install dependencies
$> npm install

## Usage
To start the React app, run:
$> npm start

Note: You need to modify package.json to set the port to 8080 by changing:

"start": "react-scripts start"

to

"start": "PORT=8080 react-scripts start"
Once started, open http://localhost:8080 in your browser to view the app.

./my_project argument1 argument2
